ВИРТУАЛЬНЫЙ ТУР «ШКОЛЬНЫЙ МУЗЕЙ ГБОУ №400» — автономная копия
================================================================

Как открыть локально (Windows):
  1. Двойной клик по run.bat
  2. Откроется браузер с туром на http://localhost:8000/
  3. Чтобы остановить — закройте чёрное окно консоли.

Почему через run.bat, а не двойным кликом по index.html:
  Панорамы работают и так, но таблички экспонатов открываются в iframe,
  а браузер блокирует локальные файлы на file:// из соображений
  безопасности. run.bat поднимает простой сервер Python — и всё работает.

Как выложить в интернет (GitHub Pages):
  Загрузите содержимое этой папки в репозиторий и включите Pages —
  тур будет доступен по публичной ссылке.

Что внутри:
  index.html        — страница тура
  tour-data.js      — описание залов, переходов и табличек
  pannellum/        — движок просмотра панорам (офлайн-копия)
  panoramas/<id>/   — плитки панорам по залам
  poi/<id>.html     — таблички с фото экспонатов
