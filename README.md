# Виртуальный тур «Школьный музей ГБОУ №400»

Автономная копия виртуального 360°-тура школьного музея на движке
[Pannellum](https://pannellum.org/). Перенесена с платформы EyeSpy360,
чтобы сохранить тур после закрытия исходного хостинга.

## Залы
- Входная зона (стартовая)
- Зал памяти Коноревой Татьяны Фёдоровны
- Александровский зал
- Кавалерский зал
- Экспозиция «Нормандия-Неман»

С информационными табличками и фотографиями экспонатов.

## Открыть локально
Двойной клик по `run.bat` (нужен Python) → браузер откроет тур на `http://localhost:8000/`.
